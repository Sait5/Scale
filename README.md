# Scale

[Открыть сайт на Vercel](https://scale-rouge-xi.vercel.app/)

Адаптивный frontend-проект на Vue 3 и TypeScript, воспроизводящий полную композицию лендинга Scale: от первого экрана и архитектуры генеративного ИИ до продуктовых секций, материалов, отзывов клиентов и футера.

Проект сочетает детальную вёрстку по макету, локализацию EN/RU и анимации интерфейса. Это статическое приложение: для запуска не требуются серверная инфраструктура, ключи API или внешние сервисы.

## Возможности

- Адаптивная компоновка для desktop, tablet и mobile, включая экраны шириной 320 px.
- Переключение английского и русского языков без перезагрузки.
- Движение декоративных дисков, подсветка архитектуры, сканирование данных и пульсация точки на карте.
- Демонстрационный печатающийся ответ в блоке Data Engine.
- Навигация по разделам, мобильное меню, карусель лекций и вкладки разметки данных.
- Форма с локальной валидацией и явным подтверждением: данные не отправляются, не сохраняются, встреча не бронируется.
- Управление с клавиатуры, видимый фокус, восстановление фокуса после диалога и поддержка `prefers-reduced-motion`.

## Технологии и архитектура

Vue 3 Composition API, TypeScript в строгом режиме и Vite. Компоненты разделены по секциям; общие кнопки, заголовки, декоративные элементы и диалог переиспользуются. Стили объединяют палитру, сетки, адаптивные правила и анимации.

```text
src/
  components/  — секции страницы и общие компоненты
  App.vue      — композиция страницы и обработчики диалогов
  i18n.ts      — состояние языка и словарь переводов
  motion.ts    — наблюдение за видимостью анимируемых блоков
  styles.css   — визуальная система и адаптивность
public/
  assets/      — локальные изображения и графика
docs/
  design-reference.md — геометрия и структура макета
```

Движение реализовано через CSS и Intersection Observer. Основные декоративные циклы приостанавливаются вне экрана и в скрытой вкладке. Печатающийся ответ — заранее подготовленный пример, а не результат обращения к языковой модели.

## Локальный запуск

Требуется Node.js 20.19+ или 22.12+ и npm.

```bash
npm install
npm run dev
```

Адрес сервера выводится в терминале; по умолчанию — `http://127.0.0.1:5173`.

## Production-сборка

```bash
npm run build
npm run preview
```

`build` проверяет типы через `vue-tsc`, затем формирует статические файлы в `dist/`. `preview` запускает сервер для проверки собранного приложения. Конфигурация Vercel использует `npm run build` и каталог `dist`.

## Дизайн и границы реализации

За основу взята полная колонка Scale AI из [макета Figma Community](https://www.figma.com/design/wODNpnb2oXhaS2iSwbxnj6/?node-id=1-11775). Сохранены порядок секций и визуальная композиция. Изображения размещены локально; декоративные диски воссозданы средствами CSS. Недоступный шрифт макета заменён на Inter с адаптированными размерами и интервалами. Лицензия шрифта находится в `public/Inter-LICENSE.txt`.

Названия брендов и надписи внутри исходных изображений не переводятся. Для материалов без целевой страницы или видео в макете показано информационное окно. Авторизация, регистрация, backend и отправка заявок не реализованы. Проект демонстрирует интерфейс и не является официальным сервисом компании.

## Проверка качества

Проверены TypeScript/Vite-сборка, компоновка на ширинах 320–1440 px, переключение языка, навигация, вкладки, закрытие диалогов клавишей Escape и сообщения валидации. При системном предпочтении уменьшенного движения эффекты отключаются.
